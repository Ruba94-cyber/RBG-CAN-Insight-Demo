# RBG CAN Insight Privacy Policy

Last updated: 11 August 2026

RBG CAN Insight is designed for local, offline CAN trace analysis.

The application processes files selected by the user on the user's device. It does not require an application account and does not intentionally upload CAN traces, databases, diagnostic descriptions, generated reports or user projects to a remote service.

RBG CAN Insight may store local preferences, recent-file references, presets, layouts and application logs on the user's device to support normal operation. Users can remove those files from the application data folder or by uninstalling the application.

No vehicle data, personal data or application telemetry is intentionally collected by RBG CAN Insight.

For support or privacy questions, contact the publisher using the support details on the [Microsoft Store product page](https://apps.microsoft.com/detail/9NTZXFCKR81D).
